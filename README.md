# Sales Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Sales Analytics Dashboard built using Microsoft Power BI**. It provides a visual overview of sales performance, customer information, and product-related data to help users explore business performance and make data-driven decisions.

The dashboard is organized into three main sections: Sales Overview, Customer Details, and Product Details.

## 🎯 Project Objectives

- Analyze sales performance through interactive visualizations.
- Explore customer-related information and patterns.
- Understand product-level performance.
- Present business data in a clear and interactive dashboard.
- Support data-driven business analysis and decision-making.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** – Dashboard development and data visualization
- **Power Query** – Data preparation and transformation, where applicable
- **DAX** – Calculated measures and analytical calculations, where applicable

## 📊 Dashboard Sections

### 1. Sales Overview
Provides a high-level view of sales performance using visual summaries and charts.

### 2. Customer Details
Presents customer-related information to help explore customer data and identify potential patterns.

### 3. Product Details
Displays product-related information to support product-level analysis and comparisons.

## ✨ Key Features

- Interactive dashboard pages
- Visual representation of business data
- Sales, customer, and product analysis
- User-friendly report navigation
- Power BI-based business intelligence and reporting

## 💼 Business Value

This project demonstrates how business data can be organized into an interactive reporting solution. It helps users explore sales, customer, and product information and supports the identification of trends and patterns for business decision-making.

## 🚀 How to Use

1. Clone or download this repository.
2. Download and install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` file in Power BI Desktop.
4. Explore the Sales Overview, Customer Details, and Product Details report pages.
5. Use the available filters and interactive visuals to explore the data.
